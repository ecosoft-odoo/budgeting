Budget activities can be configured under Settings > Technical > Budget > Budget
Activities, and their keywords under Budget Activity Keywords. Budget applications
also add these menus to their own configuration.

1.  Create an activity and give it a name.
2.  Add keywords if users should find the activity by other words. For example,
    with the keywords Ticket and Transportation on the activity Travel, searching
    Ticket in an activity field shows Travel.

Only users of the group Budget Activity Manager can create, edit or delete
activities and keywords; other internal users can read them.
