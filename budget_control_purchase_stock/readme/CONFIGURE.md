1. In **Budget > Configuration > Settings**, choose the company's **Default
   Inventory Budget Actual Source**.
2. On each **Product Category**, choose **Company Default**, **Vendor Bill**, or
   **Stock Issue Valuation** under Inventory Valuation.
3. Categories using Stock Issue must use automated inventory valuation.

The category setting is company-specific. Services and non-storable products
always use Vendor Bill. Company and category changes apply to new PO-line and
stock-move snapshots; finish open purchase/delivery flows before changing a
policy for the same product.
