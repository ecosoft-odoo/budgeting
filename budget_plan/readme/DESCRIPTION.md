This module allocates the budget of a fiscal budget period to analytic
accounts with a Budget Plan, and creates or updates their Budget Control
Sheets from it.

Budget Control Sheets created or adopted by a Budget Plan keep a direct link
to that plan. This makes ownership of the allocated amount explicit and
prevents another plan from taking over the same active sheet. Once the
module is installed, Budget Control Sheets are no longer created directly
from their menu; Lifetime budgets are still set up from their analytic
account.

Upgrading budget_control from an earlier version installs this module, which
keeps the existing plans.
